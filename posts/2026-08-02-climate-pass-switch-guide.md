## 한 줄 요약

이 글을 읽으면 **기후동행카드가 왜 멈추는지**, **기후동행패스(모두의카드·K-패스 기반)로 어떻게 갈아타는지**, 그리고 **8월 말~9월 전환 일정·대상·단기권 예외**를 공식 기준으로 확인한 뒤, 오늘 바로 카드·충전·고객센터 문의까지 끝낼 수 있다.

## 핵심 사실 (날짜·숫자·주체·조건)

| 항목 | 내용 |
| --- | --- |
| 주체 | 서울특별시 교통 정책 + 정부 모두의카드(K-패스) |
| 이슈 | 기후동행카드와 모두의카드가 비슷한 할인·정기권 성격으로 **이원화** → 시민 혼란·관리 효율화를 이유로 기후동행카드 **운영 중단** |
| 대체 서비스 | **기후동행패스** = 정부의 모두의카드(K-패스) 기반에 서울시 기후동행카드 특화 혜택을 결합한 통합 교통카드 |
| 선불 30일권 | **2026-08-31까지 충전**, 해당 충전분은 **2026-09-29까지 이용** 가능 / **9-30부터 이용 불가** |
| 후불 기후동행카드 | **2026-09-01~09-30 사용분**까지 기후동행카드 할인 혜택 적용 |

| 혜택 대상 | 기후동행패스 특화 혜택은 **서울시민** 중심. 기존처럼 누구나 쓰던 기후동행카드와 범위가 다름 |
| 경기 이용자 | 김포·고양·과천·성남·하남·남양주·구리 등 기존 이용자는 **더 경기패스** 전환 검토 |

## 지금 확인할 방법 (공식 링크)

### 1) 내 카드 유형부터 구분한다
- **선불 30일권**: 충전형 정기권. 마지막 충전·만료일이 핵심.
- **후불**: 카드사 청구형. 9월 사용분 할인 적용 여부를 본다.
- **단기권**: 1·2·3·5·7일. 종료 대상이 아님.

앱/홈에서 확인:
- 모바일: 모바일티머니 앱에서 권종·만료일 확인
- 실물: [티머니 카드&페이](https://pay.tmoney.co.kr/) 등록 카드 조회
- 정책 문의: 서울시 **02-120**(다산콜센터)
- K-패스/모두의카드 이용 문의: **031-427-4415**

### 2) 8월 말 충전 여부를 캘린더에 적는다
선불 30일권 공식 예시:
- 8월 31일까지 충전 가능
- 그 충전분이 끝나는 **9월 29일까지** 이용
- **9월 30일부터** 해당 30일권 이용 불가

“언제 마지막으로 충전할지”만 정하면, 불필요한 이중 결제·공백을 줄일 수 있다.

### 3) 기후동행패스 = 모두의카드 + 서울 특화 혜택인지 확인
서울시 공식 FAQ 기준, 기후동행패스는 모두의카드 전국 광역 혜택에 아래 특화를 결합하는 방향이다.
1. 따릉이 할인(티머니GO 카드번호 등록 방식 유지 예정, 관계기관 협의)
2. 서울달·서울식물원·서울대공원 등 문화·여가 할인
3. 청년(35~39세 확대)·제대군인 연령 연장 등 서울 특화 환급/할인

다만 **청소년 할인·제대군인 할인 일부는 국토부 협의 중**으로 적혀 있으므로, 본인 권종이 청소년이면 9월 단기권 할인(공식: 9/1부터) 안내를 같이 본다.

### 4) 거주지가 서울인지 확인한다
- 기후동행패스 특화 혜택: **서울시민**
- 경기 일부 지자체 거주자: **더 경기패스** 전환이 필요할 수 있음
- 단기권은 서울시 범위에서 계속 사용 가능

### 5) 환불·연회비 기대는 버린다
- 기존 실물 기후동행카드 구매비 환불: **불가**
- 연회비 환급: **각 카드사 문의**
- 모두의카드는 모바일·연회비 없는 체크카드 발급 경로가 있어 추가 카드비 부담을 줄일 수 있다고 안내됨

## 체크리스트 / 피해야 할 실수

### 바로 할 행동 체크리스트
- [ ] 내 카드가 선불 30일권 / 후불 / 단기권 중 무엇인지 확인
- [ ] 선불이면 만료일·잔여일수 스크린샷 저장
- [ ] 8/31 전 마지막 충전 여부를 결정(충전하면 9/29까지 사용)
- [ ] 서울시 운영종료 FAQ를 북마크: [공식 FAQ](https://news.seoul.go.kr/traffic/public/climatecard-faq/faq-stop)
- [ ] 모두의카드(K-패스) 보유 여부 확인, 없으면 고객센터(031-427-4415)로 발급 경로 확인
- [ ] 거주지가 서울이 아니면 더 경기패스 등 지자체 패스 페이지 확인
- [ ] 따릉이 이용자면 티머니GO 카드번호 재등록이 필요한지 점검
- [ ] 청소년 권종 이용자면 9/1 단기권 할인 안내를 따로 확인

### 피해야 할 실수
1. **9월에도 30일권이 그냥 될 거라 가정**하고 충전을 미루기 → 8/31 충전 마감·9/30 이용 불가.
2. **실물카드 환불받을 수 있다**고 생각하고 대기 → 공식 FAQ상 구매금액 환불 불가.
3. **경기도 거주인데 서울 기후동행패스만 기다림** → 특화 혜택 대상이 아닐 수 있음.
4. **단기권까지 종료되는 줄 알고 급하게 새 카드를 중복 발급** → 단기권은 유지.
5. **하차 미태그 습관**을 그대로 가져가기 → 기후동행카드는 하차 미태그 2회 누적 시 24시간 정지. 전환 후에도 교통카드 태그 습관은 유지하는 편이 안전하다.

## FAQ

**Q. 기후동행패스와 기후동행카드는 같은 카드인가요?**  
A. 아닙니다. 기후동행패스는 정부 모두의카드(K-패스) 기반에 서울 특화 혜택을 얹은 **통합 서비스 명칭**이고, 기존 기후동행카드(무제한 정기권형)와 결제·정산 구조가 달라 상호 호환이 어렵다고 공식 안내합니다.

**Q. 8월에 30일권을 충전하면 언제까지 탈 수 있나요?**  
A. 공식 예시 기준 **8월 31일까지 충전**한 선불 30일권은 그 충전분이 끝나는 **9월 29일까지** 이용 가능하고, **9월 30일부터는 이용 불가**입니다.

**Q. 이미 모두의카드(K-패스)를 쓰고 있으면 카드를 또 만들어야 하나요?**  
A. 서울시 FAQ는 이미 이용 중이면 **별도 추가 발급 없이** 기후동행패스 출시 후 혜택을 받을 수 있다고 안내합니다. 다만 본인 카드사·권종 화면에서 서울 특화 표기가 보이는지 한 번 더 확인하세요.

**Q. 청소년·제대군인 할인은 그대로인가요?**  
A. 일부 할인은 국토부 협의·시스템 연계 중이라고 명시되어 있습니다. 청소년은 9월 1일부터 단기권 할인으로 우선 적용하는 방안이 안내되어 있으니, 해당 권종이면 FAQ의 청소년 항목을 직접 확인하세요.

**Q. 따릉이·한강버스는요?**  
A. 따릉이는 기후동행패스(모두의카드)로 바꿔도 티머니GO에 카드번호를 넣어 할인 구매하도록 조치할 예정(협의 중)이라고 안내됩니다. 한강버스는 모두의카드에 이미 적용되어 있으며, 광역 수단으로 분리되어 이용 시마다 요금/정액 체계가 다를 수 있습니다.

## 관련 소식 + 한눈에 정리

검색어 **기후동행패스**가 오른 이유는 단순 명칭 변경 뉴스가 아니라, **8월 말 충전 마감 → 9월 전환**이 코앞이기 때문입니다.  
한눈에 정리하면:

1. **지금**: 내 카드 유형·만료일 확인  
2. **8/31까지**: 선불 30일권 마지막 충전 여부 결정  
3. **9월**: 기후동행패스/모두의카드로 전환, 단기권·청소년 안내는 FAQ 재확인  
4. **공식 창구**: 서울시 02-120 / K-패스 031-427-4415 / 티머니 1644-0088  

오늘 할 일 한 가지로 줄이면, **[운영종료 FAQ](https://news.seoul.go.kr/traffic/public/climatecard-faq/faq-stop)를 열고 내 카드 유형에 해당하는 일정 문단을 스크린샷으로 남기는 것**입니다.
