### 한 줄 요약
이 글을 읽으면 **보완수사권 폐지가 무엇인지**, 2026년 7월 29~31일 국회 처리 일정을 어디에 확인하고, **고소·고발·수사 중인 내 사건**에 당장 무엇을 점검해야 하는지 정리할 수 있습니다.

### 핵심 사실 (날짜·숫자·주체·조건)
| 항목 | 내용 |
| --- | --- |
| 이슈 | 검사의 **직접 수사·보완수사권 폐지**를 담은 형사소송법 개정안 |
| 법사위 | **2026년 7월 29일** 국회 법제사법위원회 전체회의 통과(여당 주도, 야당 퇴장) |
| 본회의 | **7월 30일** 본회의 상정 → 국민의힘 **필리버스터** 돌입 |
| 종결 동의 | 민주당이 30일 **오후 4시 6분**경 종결동의안 제출 → **31일 오후 4시 6분 이후** 종결 표결 가능 |
| 통과 전망 | 범여권 의석 구조상 **이르면 7월 31일** 표결·통과 관측(보도 기준, 확정 아님) |
| 제도 방향 | **수사는 경찰(사법경찰관), 기소·공소유지는 검사**로 역할 분리 |
| 보완수사 요구 | 검사는 직접 수사 대신 경찰에 **보완수사 요구** 가능. 경찰은 원칙 **1개월** 내 이행, 필요 시 **1개월 연장** |
| 피해자 장치 | 경찰 **불송치**에 대해 고소인·피해자뿐 아니라 **고발인 이의신청**, 사건기록 **열람·등사** 등 보도 |
| 추가 쟁점 | **중대한 위법 수사**·**소추 재량 현저 일탈** 시 공소기각 판결 사유 신설(여야 해석 대립) |
| 시행 관측 | 보도에 따르면 통과 후 **2026년 10월 공소청 출범** 이후 본격 적용 관측. **공포·시행일을 공식 확인**해야 함 |

- 국회 본회의·의사일정: [https://www.assembly.go.kr/](https://www.assembly.go.kr/)

- 현행 법령 조문 대조: [국가법령정보센터](https://www.law.go.kr/) 「형사소송법」

### 나에게 해당되는지 판별
**바로 읽어둘 사람**
- 지금 **고소·고발·고소대리**를 준비 중이거나, 경찰 수사·송치·불송치 통지를 기다리는 사람
- 피해자로서 **검사가 직접 보완수사**해 주길 기대하고 있던 사건 당사자
- 회사·학교·온라인 사건으로 **형사 절차 일정**을 잡아야 하는 실무자
- 가족·지인 사건의 단계(경찰/검찰)를 설명해야 하는 사람

**지금은 ‘일정만’ 보면 되는 사람**
- 진행 중인 형사 사건이 없고, 제도 변화만 이해하면 충분한 일반 독자
- 이미 재판(공판) 단계로 넘어가 수사권 이슈와 직접 접점이 적은 경우

**오해하기 쉬운 비대상(당장 행동이 다른 경우)**
- “오늘부터 검찰이 아무 일도 못한다”고 단정하는 경우 → **본회의 가결·정부 공포·시행일** 전이면 현행 절차가 유지될 수 있음
- 민사상 손해배상·행정심판만 있는 분쟁 → 이번 형소법 쟁점과 별개로 봐야 함

### 지금 확인할 방법 (공식 링크)
**오늘 바로 할 행동 1개:**  
국회 의안정보시스템에서 「형사소송법」을 검색해 **개정안 처리 단계(법사위/본회의/이송/공포)** 와 **의안번호**를 캡처해 두고, 내 사건이 있으면 담당 수사관·변호사에게 “송치·보완수사 요구·불송치 이의” 중 어디 단계인지 확인하세요.

단계별 확인:
1. **법안 상태 확인**  
   - [의안정보시스템](https://likms.assembly.go.kr/bill/main.do) → 검색어 `형사소송법`  
   - 표에 보이는 **제안일·소관위·본회의 결과·공포** 칸을 본다  
   - 같은 날 처리되는 **선관위 특검법**과 제목을 혼동하지 않는다
2. **본회의·필리버스터 일정 확인**  
   - [국회 홈페이지](https://www.assembly.go.kr/) 의사일정·본회의 중계로 **상정 시각·종결동의 제출 시각**을 본다  
   - 종결동의 제출 후 **24시간**이 지나야 강제 종결 표결이 가능하다는 국회법 구조를 기준으로 달력을 표시해 둔다
3. **내 사건 단계 확인**  
   - 경찰 접수번호/담당 부서, 송치 여부, 검찰 사건번호가 있는지 메모  
   - 불송치 통지를 받았다면 **이의신청 기한·방법**을 안내문에서 다시 읽는다(개정 후에도 고발인 이의 등 문구가 달라질 수 있음)
4. **현행 조문과 개정 포인트 대조**  
   - [법제처 국가법령정보센터](https://www.law.go.kr/)에서 현행 형소법 수사·송치·보완수사 관련 조항을 열어 두고, 언론에 언급된 **제195조·제196조 재편** 포인트를 메모한다  
   - “폐지됐다”는 SNS 요약 대신 **의안 원문·가결 여부**를 본다
5. **시행 전후 실무 변화 체크**  
   - 변호사·법률구조공단·대한법률구조공단 상담 시 “시행일 기준 내 사건이 경찰 단계인지”를 먼저 말한다  
   - 회사 컴플라이언스라면 내부 고소·고발 매뉴얼의 ‘검찰 직접 수사 요청’ 문구를 시행일 기준으로 수정할 준비를 한다

### 체크리스트 / 피해야 할 실수
- [ ] 법사위 통과(7/29)와 본회의 가결·공포를 **같은 말로 쓰지 않았다**
- [ ] 필리버스터·종결동의 **24시간 규칙**을 캘린더에 표시했다
- [ ] 내 사건의 **현재 관할(경찰/검찰/법원)** 을 한 줄로 적었다
- [ ] 불송치·이의신청·기록 열람 관련 안내문을 보관했다
- [ ] 공식 확인은 의안정보시스템·국회·법령센터를 쓰고, 메신저 요약만으로 단정하지 않았다
- [ ] 공소기각 사유 신설은 **여야 해석이 갈리는 쟁점**임을 구분했다

**피해야 할 실수:**  
“법사위 통과 = 이미 폐지·즉시 적용”으로 속단해 수사기관에 항의하거나, 반대로 “아직이니 아무 대비 안 함”으로 이의신청 기한을 놓치는 것입니다. **가결 여부 → 공포·시행일 → 내 사건 단계** 순서로만 판단하세요.

### FAQ
**Q. 보완수사권이 정확히 뭔가요?**  
A. 검사가 경찰로부터 송치받은 뒤, 기소 여부를 판단하기 위해 **직접 추가 수사**하거나 경찰에 보완을 요구·관여해 온 권한을 말합니다. 이번 개정 논의의 핵심은 검사의 **직접 수사(보완수사 포함)를 막고**, 필요 시 **경찰에 대한 보완수사 요구** 중심으로 바꾸자는 것입니다.

**Q. 7월 30일에 이미 폐지된 건가요?**  
A. 아닙니다. 30일은 본회의 **상정 + 필리버스터** 국면입니다. 종결동의안이 30일 오후 4시 6분경 제출됐다는 보도를 기준으로 하면, **31일 오후 이후 종결 표결**이 가능합니다. 최종 여부는 본회의 가결·정부 공포를 봐야 합니다.

**Q. 통과되면 내 고소 사건이 불리해지나요?**  
A. 사건 유형·단계마다 다릅니다. 경찰 수사 단계에서 증거·진술을 탄탄히 남기는 중요도는 커질 수 있고, 검사가 직접 보완수사하던 관행을 기대하기는 어려워질 수 있습니다. 대신 개정안에 **고발인 이의신청·기록 열람·등사** 등 피해자·고발인 측 장치가 보강된다는 보도가 있으니, 본인 사건 안내문을 기준으로 권리를 확인하세요.

**Q. 공소기각 사유 추가가 왜 싸우는 지점인가요?**  
A. 중대한 위법 수사·소추 재량 일탈을 공소기각 사유로 명문화하면, 한쪽에서는 위법 수사 통제 장치라고 보고, 다른 쪽에서는 특정 사건 방탄·재판 영향 가능성을 우려합니다. 일반 독자는 **정치 프레임보다 조문·시행일**을 먼저 확인하는 편이 안전합니다.

**Q. 어디서 공식 일정을 보나요?**  
A. 1순위는 [국회 의안정보시스템](https://likms.assembly.go.kr/bill/main.do)과 [국회 홈페이지](https://www.assembly.go.kr/)입니다. 속보성 해석은 [연합뉴스](https://www.yna.co.kr/view/AKR20260729170200001) 등으로 교차하고, 조문 대조는 [법제처 국가법령정보센터](https://www.law.go.kr/)를 사용하세요.

### 관련 소식 + 한눈에 정리
같은 본회의 축에서는 여야가 합의한 **선관위 특검법**이 먼저 처리됐다는 보도가 있습니다. 제목만 보고 형소법과 섞지 마세요. 형소법 개정안은 필리버스터 이후 **31일 표결 관측**, 제도 체감은 **공포·시행(보도상 10월 공소청 출범 전후)** 부터일 가능성이 큽니다.

| 한눈에 보기 | 체크 |
| --- | --- |
| 무엇을 | 검사 직접·보완수사 폐지 + 경찰 수사·검사 기소 분리 |
| 언제 | 법사위 7/29 통과 → 본회의 7/30 상정·필버 → 7/31 표결 관측 |
| 어디에 확인 | 의안정보시스템 · 국회 본회의 · 법령센터 |
| 나는 | 사건 단계 확인 → 불송치·이의·열람 안내 재확인 |
| 주의 | 통과 전 단정 금지, 시행일 전후를 나눠 대응 |

요약하면, 지금은 **정치 논쟁의 결론을 예단하기보다** 법안 위치(본회의/가결/공포)와 내 사건 단계를 고정해 두는 것이 가장 빠른 실무 대응입니다.
